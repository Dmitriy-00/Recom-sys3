# Recom-sys3

Бот для рекомендаций трансформативных практик и материалов.

## Быстрый старт

```bash
python -m bot.cli --goal "хочу снизить стресс" --max-duration 20
```

Для вывода в JSON:

```bash
python -m bot.cli --goal "развить эмпатию" --modality практика --as-json
```

## Тестирование

```bash
pytest
```
