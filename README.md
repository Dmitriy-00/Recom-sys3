# РЕКОМЕНДАТЕЛЬНЫЙ БОТ НА ОСНОВЕ ТРАНСФОРМАТИВНЫХ МАТЕРИАЛОВ

## Описание проекта

Это комплект документации и кода для разработки интеллектуального рекомендательного бота, который помогает пользователям находить трансформативные материалы (фильмы, книги, сериалы) для личностного роста через работу с нарративными структурами и тропами.

## Recommendation Core (Python)

В репозитории добавлен детерминированный и объяснимый модуль рекомендаций `recom_core`, который соответствует семантической модели (Obsidian → CSV → Python). Он включает:

- Чёткие модели данных (`MediaItem`, `UserProfile`, `TropePreferences`, `CognitiveGoals`)
- Загрузчик CSV (`load_media_csv`, `load_multiple`)
- Сквозной движок рекомендаций (`RecommendationEngine`) с жёсткими фильтрами и мягким скорингом
- Пример каталога `data/sample_media.csv` и сценарий запуска `examples/run_example.py`
- Поддержка пользовательских ограничений по триггерам (`avoid_triggers`) для безопасной фильтрации

### Быстрый старт (ядро рекомендаций)

```bash
python examples/run_example.py
```

Скрипт загружает тестовый каталог и выводит топ-рекомендации с расшифровкой компонентов оценки (trope/theme/cognitive/emotional/novelty и штрафы усталости).

## Ключевые концепции

### Трансформативный потенциал

В отличие от обычных рекомендательных систем, бот оценивает не только релевантность контента, но и его способность менять восприятие пользователя через:
- Смену перспективы (perspective_shift)
- Когнитивное переосмысление (cognitive_reframe)
- Эмоциональный катарсис (emotional_catharsis)
- Вызов ценностям (value_challenge)
- Расширение картины мира (worldview_expansion)
- Развитие медиа-грамотности (meta_awareness)

### Работа с тропами

Система глубоко анализирует, как материал работает с нарративными тропами:
- **Straight** - прямое классическое использование
- **Deconstruction** - разбор и критика тропа
- **Subversion** - неожиданный поворот ожиданий
- **Reconstruction** - новое осмысление после деконструкции
- **Meta** - метакомментарий о самом тропе
- **Lampshade** - явное указание на использование

### Зона ближайшего развития (ZPD)

Материалы подбираются так, чтобы быть:
- Не слишком простыми (нет роста)
- Не слишком сложными (перегрузка)
- На 1-2 уровня выше текущего (оптимальный рост)

### Треки развития

Вместо разовых рекомендаций система строит последовательности из 3-7 материалов, где каждый готовит к следующему:
- **Genre Mastery** - освоение жанра от классики до деконструкции
- **Trope Exploration** - глубокое изучение одного тропа
- **Complexity Ladder** - постепенное усложнение нарратива
- **Transformation Intensive** - серия трансформативных материалов

## Архитектура системы

### База данных

**Таблицы:**
- `materials` - все материалы с полными профилями
- `users` - профили пользователей с историей
- `tropes` - справочник тропов
- `interactions` - логирование для аналитики

**Индексы:**
- genre, complexity, transformation_score
- trope_ids для быстрого поиска
- Full-text search по контенту

### API Endpoints

**POST /recommend**
- Input: user_id, context (mood, time, goal)
- Output: топ рекомендаций с объяснениями

**POST /build_track**
- Input: user_id, goal_material_id или goal_skill
- Output: последовательность материалов с логикой

**POST /feedback**
- Input: user_id, material_id, rating, comments
- Output: обновлённый профиль и новые рекомендации

**GET /progress**
- Input: user_id
- Output: метрики роста и визуализации

## Примеры использования

### Пример 1: Новый пользователь

```python
# Создаём профиль начинающего
user = User(
    id="newbie",
    complexity_tolerance=3,
    meta_awareness_level=2,
    tolerance_for_deconstruction=2,
    favorite_genres=["action", "comedy"]
)

# Получаем рекомендации
recs = find_recommendations(user, materials_db, n=3)

# Система предложит:
# - Matrix (сложность 6) - gateway к sci-fi
# - Truman Show (сложность 6) - questioning reality
# - Princess Bride (сложность 4) - meta-aware comedy
```

### Пример 2: Путь к сложному материалу

```python
# Пользователь хочет осилить Mulholland Drive
goal = materials_db.get("mulholland_drive")  # сложность 9.5

# Строим трек
track = build_learning_track(user, goal, materials_db)

# Система построит путь:
# 1. Truman Show (6) - questioning reality
# 2. Eternal Sunshine (7) - non-linear narrative
# 3. The Fountain (8) - symbolic narrative
# 4. Mulholland Drive (9.5) - цель достигнута
```

### Пример 3: Адаптивное обучение

```python
# После просмотра
user = update_user_profile(
    user, 
    material=inception,
    rating=5,
    feedback={'breakthrough': True}
)

# Профиль обновлён:
# - meta_awareness: 2 → 2.5
# - complexity_tolerance: 3 → 3.2
# - Снята усталость от "unreliable_narrator"
```
